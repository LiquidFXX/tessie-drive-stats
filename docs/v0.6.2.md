# v0.6.2 — Home Assistant 2026.8 device-link compatibility

Version 0.6.2 keeps the v0.6.1 analytics-device organization and updates the parent/child device linking implementation for Home Assistant Core 2026.8.

## Changes

- Uses Home Assistant's current `via_device_id` device relationship instead of the deprecated identifier-based `via_device` field.
- Ensures the main Tesla device exists in the device registry before analytics child devices are created.
- Keeps VIN-based unique IDs unchanged.
- Explicitly provides stable suggested object IDs based on the Tessie vehicle name plus sensor key so analytics device names do not become part of entity IDs on new installs.
- No sensor calculations, Tessie API endpoints, entity counts, or lifetime-cache formats change.

## Device organization

The v0.6.1 grouping remains:

- Vehicle
- Driving
- Efficiency
- Charging
- Charging Economics
- Battery
- Idle & Vampire
- Lifetime
- Tires & Alerts
- Navigation & Software

The release still exposes **311 sensor entities plus 5 problem/warning binary sensors**.
