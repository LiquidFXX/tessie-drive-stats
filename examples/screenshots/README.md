# Example Screenshots

Canonical screenshot filenames used by the Examples gallery:

- `dashboard-header.png`
- `vehicle.png`
- `charging.png`
- `driving-today.png`
- `driving-this-week.png`
- `driving-this-month.png`
- `driving-this-year.png`
- `last-drive.png`
- `since-last-charge.png`
- `battery.png`
- `idle-today.png`
- `idle-this-week.png`
- `idle-this-month.png`
- `idle-this-year.png`
- `last-idle.png`
- `charging-cost.png`
- `supercharging.png`
- `tires.png`
- `navigation.png`
- `software.png`

Use descriptive lowercase names that match the visible card title. Do not use timestamp-based screenshot filenames.

Before committing screenshots, remove or obscure private information such as addresses, navigation destinations, VINs, GPS coordinates, and access tokens.
