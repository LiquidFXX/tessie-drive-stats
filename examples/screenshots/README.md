# Example Screenshots

Place Tessie Drive Stats card and dashboard screenshots in this folder.

Recommended filenames:

- `full-dashboard.png`
- `last-drive.png`
- `ap-fsd.png`
- `driving-overview.png`
- `battery-health.png`
- `since-last-charge.png`
- `idle-vampire-drain.png`
- `charging.png`
- `supercharging.png`
- `tire-pressure.png`
- `navigation-vehicle.png`
- `software-alerts.png`

Before committing screenshots, remove or obscure private information such as addresses, navigation destinations, VINs, GPS coordinates, and access tokens.
